# Aplicación Web Spring Boot MVC - Ejercicio 24: Partido Político

## Descripción
Proyecto de desarrollo web que implementa una arquitectura MVC tradicional renderizada en servidor con **Spring Boot** y **Thymeleaf**.

## Requisitos de Ejecución
- Java JDK 17
- Maven 3.8+
- Base de datos PostgreSQL (pgAdmin 4)

## Instrucciones de Ejecución Local
1. Crear la base de datos `partido_politico_db` en PostgreSQL / pgAdmin.
2. Ejecutar el script `schema.sql` en el Query Tool.
3. Configurar tus credenciales en `application.properties`.
4. Ejecutar el proyecto mediante IntelliJ o la consola:
   ```bash
   ./mvnw spring-boot:run
